# Examples

Fictional walkthroughs that show how to use this pack in practice.

All names, companies, projects, and details in this folder are made up. They
exist to make abstract concepts concrete, not to describe real projects.

## Available Walkthroughs

- `new-project-walkthrough.md` - setting up a new AI-assisted project from
  scratch
- `dual-brain-walkthrough.md` - using a strategy chat plus an execution tool in
  a tight loop
- `chaos-recovery-walkthrough.md` - stabilizing a messy AI-coded project before
  trying to scale work on top of it
- `lightweight-to-orchestration-walkthrough.md` - growing from simple repo
  memory and task packets into full doc-first orchestration only when the work
  earns it

## What These Examples Cover

- new repo setup
- dual-brain planning plus execution
- capability-aware dual-brain routing and audited closeout
- chaos recovery
- safe growth from lightweight workflow into orchestration

For a first-time collaborator or local-model helper lane, use
`LIGHTWEIGHT-COLLABORATION-GUIDE.md`. That release-critical guidance is a short
operating guide rather than a long fictional walkthrough.

## How To Use These

Skim the walkthrough that matches your situation. The point is not to copy every
line. The point is to see the workflow in motion before applying it to your own
project.
