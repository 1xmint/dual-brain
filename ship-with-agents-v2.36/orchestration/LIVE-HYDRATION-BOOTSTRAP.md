# Live Hydration Bootstrap

Use this when turning starter package state into real live system state.

## Core Truth

The package must ship neutral starter files.
The live system must quickly replace them with real truth.

## First Hydration Targets

Replace starter placeholders early in:

- `ACTIVE-WORKSTREAMS.md`
- `health/summary.json`
- `health/workstreams.json`
- `health/DASHBOARD.md`
- `observability/metrics.json`
- `observability/turn-events.jsonl`
- `observability/impact-events.jsonl`
- `workstreams/system-story.md`
- `workstreams/neighbor-digest.json`

## Final Rule

Starter state is acceptable at install time, not as a long-term operating mode.
