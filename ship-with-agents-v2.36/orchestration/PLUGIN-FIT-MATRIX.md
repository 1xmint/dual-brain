# Plugin Fit Matrix

Use this to decide whether a plugin should change the workflow recommendation.

## Good Fits

- browser or localhost verification
- HTML/CSS or visual polish work
- cross-tool retrieval
- repetitive specialized workflows

## Weak Fits

- tiny one-file fixes where a plugin adds more ceremony than value
- tasks where local repo truth is already enough
- installing a plugin only to avoid one simple manual step

## Selection Rule

Pick the plugin path when it materially improves:

- execution quality
- speed
- verification
- user experience

Otherwise keep the portable default.
