# Web Capable Lane Routing

Use this when the current lane cannot browse or when another surface is better
for external research.

## Core Truth

Not every lane needs to browse directly.
Every lane does need to know when a web-capable lane should be involved.

## Routing Rule

If external research is needed and the current lane cannot honestly do it:

- say so
- name the smallest research question
- route it to a web-capable lane or surface
- keep the packet compact

## Packet Shape

- `Research question:`
- `Why freshness matters:`
- `Preferred source tier:`
- `What decision depends on it:`
- `What artifact should be updated after research:`

## Final Rule

Capability limits are fine.
Pretending certainty because of them is not.
