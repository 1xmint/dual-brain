# Fast Path Vs Teaching Path Rule

Use this when the buyer may want both speed and optional learning.

## Core Truth

Some buyers want:

- "just do it"

Others want:

- "help me understand while we do it"

The system should support both without forking into two different products.

## Preferred Pattern

Default to the fast path.

Offer the teaching path only when:

- the buyer is new
- the buyer is shaky
- the buyer explicitly wants to learn
- the move is confusing enough that a little teaching would reduce future
  friction

## Shape

Fast path:

- recommendation
- exact next move

Optional teaching path:

- one brief extra explanation
- not a required detour

Example:

`Recommended next move: route this to manager for review. If you want the fast
path, say go and I’ll give you the ready packet. If you want the teaching path,
I can also explain why this belongs in manager instead of super.`

## Final Rule

Do not force learning on a shipping-oriented buyer.
Do not force speed on a buyer who is clearly trying to build confidence.
Do not use the teaching path as an excuse for fluff, praise inflation, or fake
certainty.
