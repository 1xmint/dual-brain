# Workstream Story Model

Use this when a workstream needs one compact narrative truth layer.

## Core Truth

Humans reason well from story:

- what is happening
- why it matters
- what just changed
- what happens next

The control plane needs one small story file for active meaningful work.

## Recommended Path

- `workstreams/<workstream-id>/STORY.md`

## Minimum Fields

- `workstream id`
- `mission`
- `scope`
- `non-goals`
- `current decision point`
- `current default recommendation`
- `execution owner`
- `review owner`
- `current risk`
- `next intended move`
- `current slice`
- `current checkpoint`

## Use

This is not a long plan.
It is the compact "current story" that keeps head, manager, super, and doctor
aligned.

## Final Rule

If the workstream feels disconnected, stale, or hard to explain, its story is
probably too weak or missing.
