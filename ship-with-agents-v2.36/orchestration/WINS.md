# WINS — Positive Institutional Memory

Patterns that worked well. Not a log — a living document of what to
repeat. Read alongside LESSONS.md on startup.

## How to use this file

When a workflow, model choice, prompt pattern, or role routing decision
works notably well:

1. Identify the pattern (not just the specific instance)
2. Write a short entry that covers when to repeat it
3. Add it here under a short heading

## Example format

**W1: [Short pattern name]**
[1-3 sentences: what worked, why it worked, when to repeat it.]
*Source: [what triggered this entry]*

## Categories to track

- **Model/effort combos** — which model at which effort nailed a task type
- **Workflow patterns** — sequences of steps that felt smooth
- **Prompt quality** — task packet formats that produced zero-drift execution
- **Role routing** — escalation or delegation decisions that saved rework
- **Tool choices** — when a specific tool, command, or feature made the difference

---

Start here and add your own patterns as you go.

## Trigger rule

Add wins at natural work boundaries:

- checkpoint writes
- handoffs
- migrations
- completion reports
- model-routing corrections

Do not force a wins review every response. Capture wins when the work
has produced enough evidence to trust the pattern.
