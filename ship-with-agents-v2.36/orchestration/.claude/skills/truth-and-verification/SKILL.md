# Truth And Verification

Use this skill whenever fluency is outrunning evidence.

## Read first

1. `TRUTH-BEFORE-ASSUMPTION.md`
2. `PERSPECTIVE-SWEEP-GATE.md`
3. `REPO-SCOPE-GATE.md` when repo boundaries matter

## Default loop

1. Name the exact truth source being used.
2. Separate observed fact from inference.
3. If an inference is still necessary, label it and bound its risk.
4. If external freshness could change the answer, route to research instead of
   pretending certainty.

## Watch for

- routing guesses described as settled truth
- repo-scope assumptions made from memory
- one plausible local angle mistaken for the whole picture
- buyer reassured before evidence exists

## Output shape

- `Observed truth:`
- `Inference:`
- `Risk if wrong:`
- `Next verification step:`
