coherent organism-level picture.

- `workstreams/system-story.md`

- meaningful recent changes
- hot workstreams

- conflicts or opportunities
- best next system move

- `SYSTEM-STORY-DIGEST.md`
- `ACTIVE-WORKSTREAMS.md`
