---
description: Check whether a manager or super is carrying too many hot burdens
---

Assess current context purity for the active review/execution lanes.

Check:

- number of hot workstreams
- repo overlap
- launch-boundary churn
- waiting lanes blocked on one reviewer
- whether one manager is becoming a bottleneck

Return:

1. `Context purity:` `clean / stretched / overloaded`
2. `Current bottleneck:`
3. `Smallest honest fix:`
