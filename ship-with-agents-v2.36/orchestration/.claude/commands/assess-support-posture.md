# /assess-support-posture

Use this when a buyer-facing response feels technically correct but may need a
better support fit.

## Do

1. inspect the smallest relevant user signal and local preference truth
2. classify the right posture:
   - `shipping`
   - `guided`
   - `teaching`
3. state why in one short sentence
4. recommend the smallest explanation depth that preserves confidence

## Output

- `Support posture:`
- `Why:`
- `Explanation depth:`
- `Tail style hint:`

## Rule

Do not use this to justify unnecessary verbosity.
Use it to avoid coldness, confusion, or over-explaining.
