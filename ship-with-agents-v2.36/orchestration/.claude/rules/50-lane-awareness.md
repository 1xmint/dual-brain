# Lane Awareness Discipline

- before real work after startup or resume, resolve identity and run a startup
  self-check
- a meaningful live lane should have:
  - active-map row
  - inbox file
  - lane brain capsule
  - workstream linkage when applicable
- do not say "no inbox" until identity resolution and lifecycle repair have
  both been considered
- use the lane broker before adding heavier structure by habit
