# Review Topology Rule

- Use `REVIEW-TOPOLOGY-LADDER.md` when review density is the real question.
- One manager should not silently become a quality bottleneck for multiple hot
  supers.
- Keep provider choice in metadata, not in role names.
- Prefer one clean review/execution cell over several decorative extra lanes.
- Pair topology choice with `REVIEW-STATE-MACHINE.md`; topology without active
  state is not enough.
