# Collective Intelligence Rule

- Treat meaningful work as connected cells, not isolated chats.
- If one cell changes something that should affect another, trace the impact
  before stopping.
- Prefer impact-based routing over broad broadcast.
- When structure is changing, ask whether the system needs replan, merge,
  split, or pause behavior.
- Do not leave cross-workstream dependencies, conflicts, or opportunities only
  implicit in chat memory.
