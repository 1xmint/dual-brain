# docs/INDEX.md

Global index of lifecycle artifacts across all stages.

This index is for lifecycle docs, not live execution slices.

## v2.0 -- manual regeneration

This file is regenerated by the head on session close. Format is
one line per artifact:

```
id | slug | stage | owner | last_touched | one-line summary
```

Per-folder INDEX.md files hold the same format scoped to their stage.
This file aggregates them.

**Future tooling will automate this.** The planned CLI command is:

```
swa lifecycle list
swa lifecycle list --stage proposal --owner head
swa lifecycle resolve lc-20260426-friction-aggregation
```

Until then, regenerate manually after any stage promotion.
