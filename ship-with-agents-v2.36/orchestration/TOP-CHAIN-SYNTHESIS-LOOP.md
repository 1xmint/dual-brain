# Top Chain Synthesis Loop

Use this when head or manager needs to think across several live cells at once.

## Core Truth

Top-chain quality is not only better judgment.
It is better synthesis.

## Read Order

1. `ACTIVE-WORKSTREAMS.md`
2. `health/workstreams.json`
3. `workstreams/system-story.md`
4. `workstreams/neighbor-digest.json`
5. `observability/impact-events.jsonl`
6. the smallest relevant slice, checkpoint, or closeout

## Questions To Answer

- what changed recently that matters system-wide
- where does one cell affect another
- where is a merge, pause, or replan warranted
- what is the smartest next topology

## Final Rule

Top-chain lanes should synthesize from living shared truth, not from isolated
chat memory and static role assumptions.
They should also preserve mission boundaries instead of treating adjacent
context as permission to widen scope.
