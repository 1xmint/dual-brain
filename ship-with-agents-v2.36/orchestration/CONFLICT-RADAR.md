# Conflict Radar

Use this when multiple workstreams may collide or silently duplicate effort.

## Conflict Types

- same shared surface
- incompatible contract assumptions
- overlapping ownership
- hidden dependency order
- duplicate solution effort

## Output Shape

- `Conflict risk:`
- `Why:`
- `Affected workstreams:`
- `Required action:`

## Final Rule

Conflict radar should warn before merge pain, not only after it.
