# Security And Docs Research Protocol

Use this before high-risk implementation or confidence claims.

## Mandatory Triggers

- auth
- secrets
- crypto
- network exposure
- payments
- privacy
- dependency upgrade with behavior or policy risk
- version-specific framework changes

## Required Research Shape

- current official docs
- current security or release notes if relevant
- primary source confirmation for behavior that affects design

## Output

- `Research trigger:`
- `Sources checked:`
- `What changed in the recommendation:`
- `Residual uncertainty:`

## Final Rule

Do not call a security-sensitive plan complete from stale local intuition.
