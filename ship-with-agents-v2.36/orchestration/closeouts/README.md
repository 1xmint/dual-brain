# Closeouts Directory

Use this for canonical closeout packets when work needs stronger archival truth
than "the checkpoint looks done."

Store live or final closeout packets in:

- `_agent-system-runtime/closeouts/<workstream-slug>.md`

Use this especially when:

- assurance level is `A2` or `A3`
- the work changed durable product or system direction
- the next phase depends on a trustworthy summary of what was actually checked
- the lane is closing and you do not want the buyer reconstructing closeout
  truth from scattered chat messages

Pair this with:

- slice doc = planning and review truth
- checkpoint = latest execution truth
- closeout packet = final closure truth

See `TEMPLATE.md` for the format.
