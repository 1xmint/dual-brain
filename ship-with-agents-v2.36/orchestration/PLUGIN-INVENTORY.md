# Plugin Inventory

Starter plugin truth for this package.

Fill this in for your own live system so lanes can tell the difference between:

- already installed
- marketplace-available
- suggested but unverified
- unavailable

## Starter Sections

- desktop/app plugins actually available now
- terminal plugin marketplaces available now
- verified installed task-specific plugins
- suggested but not installed plugins

## Final Rule

Plugin truth should be specific enough that a lane can say:

- `use it now`
- `suggest installing it`
- or `fall back without it`

without guessing.
