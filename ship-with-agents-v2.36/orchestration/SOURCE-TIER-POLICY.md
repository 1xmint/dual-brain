# Source Tier Policy

Use this when external research is needed.

## Preferred Source Order

1. official docs, standards, vendor guidance
2. primary repos, issues, specs, release notes
3. strong secondary technical sources
4. community discussion only when clearly labeled

## Rules

- prefer primary sources when the question is technical
- use community sources to discover possibilities, not to replace official
  truth
- distinguish sourced facts from strategic inference
- keep citations compact and decision-relevant

## Final Rule

The better the source, the less cleanup doctor needs later.
