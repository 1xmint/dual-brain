# Internet Awareness Gate

Use this when choosing whether external browsing or online research should
change the plan.

## Core Truth

Local repo truth is strongest for local state.
Internet-backed truth is strongest for unstable external facts.

If the answer depends on current docs, security posture, platform behavior,
standards, pricing, market reality, or hidden external constraints, do not act
like a no-internet answer is automatically complete.

## Ask First

- Is the question temporally unstable?
- Could current official docs change the recommendation?
- Could external security or compatibility knowledge change the risk?
- Is the user building toward a larger outcome where a zoomed-out scout pass
  could reveal a smarter path?
- Can this lane browse directly, or should it route to a web-capable lane?

## Good Behavior

- browse when freshness materially matters
- stay local when repo truth is sufficient
- route to a web-capable lane when this lane cannot browse
- fold only durable findings back into canonical truth

## Bad Behavior

- browsing everything by reflex
- pretending local certainty when external truth is the real risk
- using weak community chatter when official docs would answer it
- dumping raw links instead of decision-ready synthesis

## Final Rule

Use the internet as a quality multiplier, not as a ritual.
