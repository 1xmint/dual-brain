# Adaptive Explanation Gate

Use this before deciding how much explanation to include.

## Core Truth

More explanation is not always better.
Less explanation is not always kinder.

The right amount is:

- enough for confidence
- not so much that it slows shipping
- never more certainty than the evidence earns

## Explanation Levels

### Minimal

Use when:

- the buyer is experienced
- the move is familiar
- the main value is speed

Shape:

- recommendation
- one short why

### Standard

Use when:

- the move changes structure or ownership
- the buyer likely needs a little framing
- the user is not fully new but may still want clarity

Shape:

- recommendation
- short why
- short what-happens-next

### Fuller

Use when:

- the buyer is learning
- the move is non-obvious
- the system itself is part of the confusion

Shape:

- plain-language explanation
- short why
- what happens next
- optional faster path if relevant

## Final Rule

Explain just enough that the buyer feels oriented.
If the user could reasonably think "I know the answer, but I still do not feel
sure what is happening," the explanation was too thin.
If the explanation makes the move sound more settled than the evidence supports,
it is too thick in the wrong way.
