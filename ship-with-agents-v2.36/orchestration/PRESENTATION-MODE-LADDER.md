# Presentation Mode Ladder

Use this after intent is compiled and before finalizing the buyer-facing
response.

## Core Truth

The system should choose not only the right answer, but the right form for the
answer.

## Modes

### Mode 0 - Plain Text

Use when:

- one short recommendation is enough
- no visual structure is needed

### Mode 1 - Text Plus Compact Bullets

Use when:

- two to five distinct points matter
- the user needs quick scanability

### Mode 2 - Text Plus Table

Use when:

- the user is comparing options
- chunks, owners, or tradeoffs are easier in rows

### Mode 3 - Text Plus Mermaid

Use when:

- process flow
- orchestration shape
- roadmap sequencing
- branching logic

materially benefit from a visual.

### Mode 4 - Text Plus Image

Use when:

- the problem is truly spatial or visual
- a chart, mockup, or rendered image buys more than markdown structure

## Selection Questions

Ask:

1. what is the buyer trying to understand?
2. what would make this obvious fastest?
3. is a visual helpful, or just impressive-looking?
4. does the current surface support the richer mode cleanly?

## Final Rule

Do not default to the richest mode.
Default to the clearest one.
