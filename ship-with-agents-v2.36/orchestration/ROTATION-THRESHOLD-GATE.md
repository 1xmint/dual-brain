# Rotation Threshold Gate

Use this before rotating a head, manager, super, agent, or doctor lane.

## Core Truth

Rotation is a context decision, not a productivity badge.

Rotate because the current chat is no longer the right container.
Do not rotate just because some work happened.

## When Rotation Is Appropriate

Rotate when all of these are true:

1. the same lane still owns the same workstream or tightly related next phase
2. the current session is losing clarity, salience, or retrieval quality
3. a tighter summary would improve the next phase materially

## When Not To Rotate

Do not rotate when:

- the workstream actually changed and wants a new sibling lane
- the ownership function changed
- the prior lane already closed cleanly
- the user is really asking for a new bounded review or execution lane
- a compact would solve the problem without creating more lane surface area

## Final Rule

Do not use rotation tokens to represent progress.
Use them only to represent continuation of the same lane after a planned
container reset.
