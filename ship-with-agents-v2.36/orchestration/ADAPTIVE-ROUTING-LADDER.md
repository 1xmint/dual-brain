# Adaptive Routing Ladder

Use this when choosing the workflow shape for a task.

## Level 0 - Stay Here

Use when:

- the task is tiny
- it is easy to reverse
- one lane can own it honestly

## Level 1 - Direct Agent

Use when:

- the task is bounded
- execution is real
- one durable owner helps
- a super lane would be overhead

## Level 2 - Super Plus Agent

Use when:

- multiple steps or likely follow-ups exist
- execution needs coordination, checkpoints, or sequencing

## Level 3 - Manager-Style Challenge Plus Super

Use when:

- scope quality is still uncertain
- launch readiness deserves active challenge
- weird-but-test-passing mistakes would be costly

## Level 4 - Multiple Managers Or Multiple Supers

Use when:

- multiple repos or major tracks are active
- one owner would become a bottleneck
- parallelism value is strong and the collision map is honest

## Inputs That Matter

Always consider:

- task size
- blast radius
- reversibility
- parallelism value
- review value
- repo scope
- live surface capability
- operator budget posture
- operator appetite for extra lanes

## Speed Rule

If a heavier level does not buy:

- better quality
- clearer ownership
- more trustworthy parallelism
- or less buyer busywork

stay one level lighter.

If the new question is still inside the same hot workstream, also count the
coordination cost of a fresh lane before climbing upward.
