# Passive Routing Vs Active Pickup Protocol

Use this after internal routing succeeds.

## Core Truth

Continuity and momentum are different.

Internal routing preserves continuity.
It does not prove the next owner is actively moving.

## Passive Routing

Passive routing means:

- inbox note written
- update-bus entry published
- canonical artifact updated

This is enough only when waiting for the next normal pickup moment is acceptable.

## Active Pickup

Active pickup is required when:

- production should likely continue now
- dual-brain challenge is supposed to continue now
- the next owner is live but passive
- the current answer would otherwise end with "they have not picked it up yet"

## What To Do

If passive routing is not enough:

- surface one tiny pickup trigger, or
- use `Recommended next move:` when the buyer should lightly steer the ownership move
- if the buyer should steer the move, include the exact bridge artifact in the
  same turn

## Anti-Patterns

- `No user action needed:` after routing when the lane itself knows momentum is
  still stalled
- treating inbox write success as proof that the next owner is now acting

## Final Rule

Do not let a successful handoff report masquerade as active production.
