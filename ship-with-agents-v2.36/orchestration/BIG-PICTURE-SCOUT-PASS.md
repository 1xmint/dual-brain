# Big Picture Scout Pass

Use this when the user is building toward an outcome and a zoomed-out view
could reveal hidden options, risks, or shortcuts.
For a broader internal quality guard across meaningful work, also run
`PERSPECTIVE-SWEEP-GATE.md`.

## Ask

- What larger goal is the user really building toward?
- What external shift, pattern, standard, or platform capability could change
  the plan?
- Is there a simpler, safer, or faster path that local context alone will not
  reveal?
- What should be researched before we narrow into implementation?
- What existing internal docs or workstream artifacts should be read before we
  treat the current local thread as the whole picture?

## Outputs

- `Big-picture goal:`
- `External unknowns that matter:`
- `What a scout pass could change:`
- `Recommended research lane or command:`

## Final Rule

Do not stay zoomed in so long that hidden external reality makes the local plan
smaller than it should be.
