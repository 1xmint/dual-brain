# Cross-Lane Awareness Rule

Use this when deciding how much every lane should know versus what doctor
should know.

## Core Truth

Do not try to make every lane omniscient.

That weakens execution and bloats context.

## Good Split

- every lane should know itself well
- the control plane should know active structure well
- doctor should know the system broadly enough to survey and improve it

## Lane Minimum

Each live lane should know:

- who it is
- what it owns
- what inbox is theirs
- what workstream it belongs to
- what happens next
- what nearby cells it should care about

## Doctor Maximum

Doctor should be able to answer:

- which lanes are actually live
- which are stale or orphaned
- what the system most recently told the buyer
- where frustration is accumulating
- which fixes changed behavior and which did not

## Final Rule

System awareness should be layered, not evenly smeared across every chat.
Meaningful lanes should know their neighborhood; doctor and the control plane
should know the wider organism.
