# Smart Next-Step Framing

Use this when the right answer is not just "do X," but "first figure out A,
then do B, then shape C."

## Core Truth

A smart system should not sound scattered when the right path has several
stages.

## Output Shape

Return:

- `What we know:`
- `What we still need:`
- `I recommend:`
- `What happens after go:`

If a follow-on sequence exists, prefer one default next move plus one short
reason over a flat list of equally weighted next frontiers.

If the steps are process-heavy, pair this with a table or Mermaid flow.

## Final Rule

Multiple steps are fine.
Unframed multiple steps are not.
