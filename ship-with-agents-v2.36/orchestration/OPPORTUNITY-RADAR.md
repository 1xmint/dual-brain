# Opportunity Radar

Use this when the system should notice upside, not only failure.

## Opportunity Types

- safe new parallelism
- merge two overlapping cells
- downgrade a heavy lane to direct agent
- upgrade a weak review path to dual-brain
- reuse a lesson or pattern from another repo or workstream
- turn repeated friction into a new command, rule, or fixture

## Output Shape

- `Opportunity:`
- `Why now:`
- `Expected payoff:`
- `Cost to act:`
- `Best next owner:`

## Final Rule

The living system should not only catch what is broken.
It should also spot what is newly possible.
