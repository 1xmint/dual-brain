# Plugin Awareness Gate

Use this when a task might benefit from installed plugins, marketplace plugins,
or skills that materially improve execution quality or user experience.

## Core Truth

Plugins are a first-class capability layer, not an afterthought.

If a relevant plugin is already installed or clearly available, the system
should not keep acting like the only tools are the default built-ins.

## Required Sources

Before ignoring plugin help, check:

1. `PLUGIN-INVENTORY.md`
2. `OPERATOR-CAPABILITIES.md`
3. `OPERATOR-PREFERENCES.md`
4. `SURFACE-CAPABILITY-PROFILE.json`

## Final Rule

Installed or clearly available plugins should be considered deliberately, not
forgotten and not overused.
